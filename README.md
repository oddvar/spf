# spf2026

A new workspace scaffold for `spf2026`.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Build the project:
   ```bash
   npm run build
   ```
3. Run the output:
   ```bash
   npm start
   ```

## Development

- `npm run dev` - watch TypeScript compile in `src`
- `npm run lint` - run ESLint
- `npm run format` - format files with Prettier
